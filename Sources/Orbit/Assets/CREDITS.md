# 纹理来源

- Earth: NASA Earth Observatory, Reto Stöckli, [Blue Marble Next Generation with Topography and Bathymetry, August 2004](https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-topography-bathymetry/).
- Moon: NASA Scientific Visualization Studio / Ernie Wright, [CGI Moon Kit, LRO/LROC/LOLA data](https://svs.gsfc.nasa.gov/4720/).
- [NASA images and media usage guidance](https://www.nasa.gov/nasa-brand-center/images-and-media/).

地球与月球纹理由上述影像缩小得到，用于主界面的 3D 显示。

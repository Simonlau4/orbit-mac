# Orbit 功能说明

当前版本：0.4.4。运行要求为 macOS 14 或更新版本。

## 功能与适用条件

| 功能 | 行为 | 适用条件 |
| --- | --- | --- |
| Orbit 更新提醒 | 启动及运行中每 6 小时检查 GitHub Releases；主窗口、菜单栏和设置提供新版入口 | 需要联网；只提示含通用安装包的更高版本，确认后打开下载页面 |
| 统一扫描 | 读取应用、浏览器、通讯、开发与 AI 工具的已知目录，以及系统缓存、废纸篓和旧安装包 | 按设备与 inode 去重；不可读或未完成的范围显示部分覆盖 |
| 扫描结果 | 按“推荐清理”和“需要你决定”分组，展示用途、路径与清理后果 | 仅推荐层默认勾选；运行中与近期数据保留 |
| 项目构建产物 | 将 `.next`、`.build`、项目内 `DerivedData` 作为整体审阅 | 7 天无改动、项目中无工作进程；移动前复核目录；链接及受保护目录保留 |
| 读取权限 | 逐路径检测当前进程读取结果，提供系统设置、定位应用与重扫入口 | 完全磁盘访问由用户在 macOS 设置中授予 |
| 普通清理 | 将选中的缓存、日志、构建产物和旧安装包移入废纸篓 | 执行前复核文件与运行状态，记录支持逐项恢复 |
| AI 清理 | 审阅 Codex、Claude Code、Cursor、Pi、Ollama 的缓存、旧版本、会话、worktree、模型及程序包 | 独立选择；活动工具、记忆、技能和共享依赖保留 |
| 软件管理 | 列出应用、关联数据、可能残留、官方更新与个人启动项 | 关联数据默认保留；运行中与系统应用保留 |
| 软件更新 | 核对 HTTPS 更新源、签名、开发者、标识、架构与系统版本，安装后可回退 | 自动更新等待应用退出；管理员安装单独确认；PKG 由系统安装器处理 |
| 系统监测 | CPU、内存、网络、磁盘、进程、电池与传感器指标 | 首个差值样本建立基线；电池健康度为容量估算 |
| 风扇控制 | 自动、降温、强冷；独立管理员组件、10 秒租约与 30 分钟上限 | 需要硬件支持与开发者签名；租约失效、睡眠或退出时恢复自动 |
| 目录分析 | 树图、下钻、大文件、隐藏项与排序 | 展示逻辑文件大小；APFS 共享块与快照会影响和系统占用的比较 |
| 常亮与屏幕清洁 | 定时阻止休眠，黑色屏幕清洁覆盖 | 退出释放电源请求；屏幕清洁可按 Esc 退出，失焦或 30 秒后结束 |

## 系统维护

维护先检查与预览，再按选择执行。文件和数据库变更保存恢复记录。

| 检查项 | 处理方式 |
| --- | --- |
| 已移除应用的命令 | 审阅指向缺失应用的个人命令链接 |
| 应用休眠与镜像校验覆盖 | 移除明确为真的旧覆盖键，保留原偏好设置 |
| 失效登录项 | 解析目标并区分外置磁盘，系统项目交由系统设置管理 |
| 失效后台服务 | 审阅目标已不存在且未加载的个人 LaunchAgent |
| 下载隔离记录 | 备份后在数据库副本中处理记录 |
| 旧窗口状态 | 核对目录与内部文件年龄，保留运行中应用 |
| 闲置磁盘镜像 | 审阅后正常卸载，由系统处理使用中状态 |
| 内存压力 | 在存在压力时提供需要管理员认证的 purge |
| 旧通知 | 核对数据库结构与时间字段后处理副本 |
| Spotlight 规则 | 审阅属于已移除第三方应用的规则 |
| Quick Look 生成器 | 调用系统 `qlmanage -r` |
| 文件缩略图 | 调用系统 `qlmanage -r cache` |
| 损坏配置 | 隔离无法解析的第三方 plist |
| 用户目录权限 | 单独确认后调用系统权限重置工具 |
| 最近使用与边栏列表 | 隔离损坏的列表文件 |
| 例行维护 | 系统提供 `periodic` 时执行对应维护项 |
| Mail、Messages、Safari 数据库 | 一致性备份后在副本中执行 VACUUM，再替换原文件 |

管理员操作由 macOS 请求认证。各维护项的可用性取决于当前系统、权限与应用状态。

## 记录与恢复

| 记录 | 默认位置 |
| --- | --- |
| 普通清理 | `~/Library/Application Support/Orbit/cleanup-history.json` |
| AI 数据恢复 | `~/Library/Application Support/Orbit/AIRecovery` |
| 维护恢复 | `~/Library/Application Support/Orbit/MaintenanceRecovery` |
| AI 程序包恢复 | `~/Library/Application Support/Orbit/AIPackageRecovery` |
| 停用的个人启动项 | `~/Library/Application Support/Orbit/DisabledLaunchAgents` |
| 普通更新旧版 | 应用同目录的 `.OrbitBackup-<UUID>.app` |
| 管理员更新旧版 | `/Library/Application Support/Orbit/UpdateAgent/<uuid>/backup.app` |

恢复副本仍占磁盘空间。恢复时会检查原位置冲突、备份变化和数据库新内容。

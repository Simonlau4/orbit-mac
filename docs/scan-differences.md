# 扫描范围与计量

## 扫描范围

普通扫描读取明确的缓存与日志目录，包括用户 `Library/Caches`、`Library/Logs`、Containers 与 Group Containers 中的缓存叶、已知 Application Support 缓存叶，以及 npm、pip、Bun、Corepack、fontconfig 等工具的缓存。

浏览器仅检查已知 Cache、Code Cache 和组件缓存目录。安装包检查下载目录根部的 DMG 与 PKG。项目构建产物在 `~/Developer`、已知 AI worktree 与 `~/Documents/Codex` 工作目录中按层级和条目预算发现。

| 范围 | 处理方式 |
| --- | --- |
| 应用、浏览器、通讯缓存 | 按路径、应用归属、运行状态和年龄判断 |
| 开发工具缓存与日志 | 按已知缓存叶和年龄判断 |
| 项目 `.next`、`.build`、`DerivedData` | 整体审阅，至少 7 天无改动且项目中无工作进程 |
| 下载目录中的旧 DMG、PKG | 默认至少 30 天，逐项选择 |
| AI 缓存、旧版本、会话与模型 | 统一扫描统计，在独立 AI 页面审阅 |
| 系统缓存、系统日志、已有废纸篓 | 只统计占用 |
| 离线数据、数据库、工作区状态与扩展 | 只统计并保留 |
| 共享归属未核实的数据 | 只统计并保留 |

普通清理默认年龄为：应用与浏览器缓存、软件包下载缓存 7 天，日志 14 天，Xcode DerivedData 与下载目录安装包 30 天。设置中可选择包含近期可重建缓存。

## 占用与候选

- **占用**：已读取文件的逻辑大小，包括需要保留的内容。
- **候选**：满足当前清理规则、可以进入审阅的内容。
- **已选**：用户当前选择的候选。
- **保留**：运行中、近期、共享、未知归属或其他规则要求保留的内容。
- **部分覆盖**：权限拒绝、I/O 变化、预算或取消导致扫描未完成，已知占用按下界展示。

扫描按设备与 inode 去重，区分路径占用和去重贡献。逻辑文件大小与 APFS 实际可释放空间可能不同；移入废纸篓不会立即释放空间，恢复副本也继续占用磁盘。

## 文件与运行状态

运行中的应用缓存保留。浏览器的 Cookie、历史和密码、AI 记忆与技能、数据库及其 WAL/SHM 文件不会作为普通缓存候选。符号链接、硬链接与锁文件按各自规则保留。

项目构建产物移动前重新核对目录指纹、文件数、大小与最近改动。包含硬链接、根为符号链接或位于 `.codex` 下的构建保留。

普通扫描读取文件元数据，AI 会话内容通过独立审阅处理。修改清理类别或近期缓存设置后，旧结果与选择失效。

## 读取权限

“读取权限”检测当前 Orbit 进程对具体目录的实际读取结果。需要更多权限时，可打开 macOS 完全磁盘访问设置、定位应用，完成授权后重新检测与扫描。

不可读目录显示实际错误，未知大小按未知或下界处理。系统保护仍可能限制部分路径，即使已经授予完全磁盘访问权限。

扫描有目录层级、条目、文件数与时间预算；达到上限或取消时显示未完成状态。清理准入独立于占用统计，新增统计范围不自动产生可删除候选。
